이번 실험은 다음 세 질문을 분리하여 확인했다.

## 4. A3: beta가 커질 때 수렴이 느려지는 이유

tol=1e-10, 노드 1,200개에서 beta를 0.5, 0.7, 0.85, 0.95, 0.99로 늘리면 반복 횟수는 14, 17, 20, 23, 24회였다. 20,000개에서는 14, 18, 21, 24, 25회였다.

Beta는 링크 이동 확률이다. Beta가 커질수록 순간이동이 줄고 링크를 통해 전달되는 기존 분포의 영향이 더 오래 남는다. beta<1인 PageRank 갱신은 L1 차이에 대해 수축 성질을 가지는데, beta가 커질수록 보장되는 수축이 약해진다. 이는 더 많은 반복이 필요해질 수 있는 이유이다.

이 그래프에서는 증가 폭이 비교적 작았다. 실제 수렴률은 링크 구조와 초기 상태에도 영향을 받으므로 beta만으로 반복 횟수를 예측하거나 다른 그래프에 이 값을 그대로 적용할 수는 없다.

## 5. A4: 노드 수, 반복 횟수와 실행 시간

노드 수를 약 16.67배 늘렸을 때 tol=1e-10의 비교는 다음과 같다.

| beta | 반복: 1,200개 → 20,000개 | 시간(s): 1,200개 → 20,000개 |
|---:|---|---|
| 0.5 | 14 → 14 | 0.007224 → 0.135045 |
| 0.7 | 17 → 18 | 0.008554 → 0.164187 |
| 0.85 | 20 → 21 | 0.009652 → 0.191569 |
| 0.95 | 23 → 24 | 0.011082 → 0.220668 |
| 0.99 | 24 → 25 | 0.011712 → 0.226549 |

반복 횟수는 같거나 1회 증가하여 노드 수에 비례하지 않았다. 그러나 beta=0.85의 시간은 0.009652초에서 0.191569초로 약 19.85배 증가했다. 반복 횟수가 비슷해도 매 반복에서 순회하는 노드와 링크 수가 늘어나기 때문이다.

따라서 수렴률과 반복당 작업량은 구분해야 한다. 이 결과는 측정 전 예상과 부합한다. 다만 크기를 바꾸면 생성되는 그래프도 바뀌고 dead end 수는 12개로 유지되므로 dead end의 비율도 달라진다. 크기만 바꾸고 다른 구조를 완전히 통제한 비교는 아니다.

## 6. A5: 허용 오차와 자릿수당 비용

1e-3과 1e-10의 절대 차이는 1e-4 이상이므로 과제 조건을 만족한다. beta=0.85에서의 결과를 따로 비교하면 다음과 같다.

| 노드 수 | tol=1e-3 | 1e-4 | 1e-6 | 1e-8 | 1e-10 |
|---:|---:|---:|---:|---:|---:|
| 1200 | 7 | 9 | 12 | 16 | 20 |
| 20000 | 8 | 9 | 12 | 17 | 21 |

1e-4→1e-6→1e-8→1e-10은 각각 두 자릿수씩 더 엄격한 기준이다. 추가 반복 횟수를 2로 나누어 한 자리당 평균 비용을 계산했다.

| 노드 수 | 1e-4→1e-6 | 1e-6→1e-8 | 1e-8→1e-10 |
|---:|---:|---:|---:|
| 1,200 | 1.5회/자리 | 2.0회/자리 | 2.0회/자리 |
| 20,000 | 1.5회/자리 | 2.5회/자리 | 2.0회/자리 |

이 구간의 비용은 약 1.5–2.5회/자리였다. 변화량이 기하급수적으로 감소하는 구간에서는 허용 오차의 자릿수 증가에 따른 반복 비용도 비교적 비슷해진다. 그러나 일정한 보편값은 아니다.

Tol은 연속된 두 점수 벡터의 L1 차이 기준이다. tol=1e-10이라고 해서 모든 점수의 최종 정답 오차가 1e-10 이하로 직접 보증되는 것은 아니다.

## 7. A6: 상위 10개 순서와 beta의 영향

허용 오차 영향을 줄이기 위해 tol=1e-10 결과끼리 비교했다.


### 노드 1,200개

| beta | 상위 10개 순서 |
|---:|---|
| 0.5 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00000 → p00004 → p00007 → p00008 |
| 0.7 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.85 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.95 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.99 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |

### 노드 20,000개

| beta | 상위 10개 순서 |
|---:|---|
| 0.5 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00000 → p00004 → p00007 → p00008 |
| 0.7 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.85 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.95 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.99 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |

두 그래프 모두 beta=0.5에서는 p00000이 p00004보다 앞섰고, beta=0.7부터는 p00004가 p00000보다 앞섰다. 상위 10개에 포함되는 노드 집합은 같았지만 7위와 8위의 순서가 바뀌었다.

따라서 **측정한 beta 중 최초 순서 변화는 0.7**이다. 0.5와 0.7 사이를 더 세밀하게 측정하지 않았으므로 정확한 순위 교차 지점은 확인하지 않았다. 0.7, 0.85, 0.95, 0.99에서는 이 상위 10개 순서가 같았다.

순위 발표에서 beta는 결과를 만드는 모델 가정이다. 결과를 비교하거나 신뢰도를 판단하려면 beta, 수렴 조건과 그래프를 함께 알아야 한다. 이번 결과를 모든 데이터의 순위 안정성으로 일반화할 수는 없다.
